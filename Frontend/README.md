# 📸 InstaClone - Full Stack Social Media App

A full-stack Instagram-like social media application built with **React + Vite** frontend and **Express + MongoDB** backend.

## 🔥 Features

- ✅ User authentication (JWT-based)
- 📸 Create and edit posts (with image upload & captions)
- 💬 Comment, like, bookmark functionality
- 🌙 Dark mode support
- 🖼️ Responsive + Mobile-first post dialog with animations
- 🧑 View profiles, followers/following
- 🔍 Search users
- 💾 Backend file uploads using Multer

## 🛠️ Tech Stack

### Frontend
- React + Vite
- Redux Toolkit
- Tailwind CSS
- Shadcn UI
- Axios
- Lucide Icons

### Backend
- Node.js + Express
- MongoDB + Mongoose
- Multer (image uploads)
- Socket.io (optional for realtime features)
- JWT Auth
- CORS, Cookie-parser

## 🚀 How to Run Locally

### 1. Clone the repo
```bash
git clone https://github.com/khushbu2784/InstaClone.git
cd InstaClone
````

### 2. Setup Backend

```bash
cd Backend
npm install
npm run dev
```

### 3. Setup Frontend

```bash
cd ../Frontend
npm install
npm run dev
```
